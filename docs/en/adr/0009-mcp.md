# ADR-0009: MCP: tools through the same gate, configuration behind the trust gate

**Status:** Accepted · **Date:** 2026-10-29

## Context

MCP servers add unlimited external tools to usta. There are two risks: (1) tools give the model power but a server's claims (such as "read-only") cannot be verified; (2) if the configuration comes from a repository, its `command` field starts arbitrary programs on the user's behalf.

## Decision

1. **The same gate.** MCP tools are adapted to the `Tool` interface (`mcp__server__tool`); the permission engine, hooks, checkpoints, the output limiter and the `auto` classifier all apply unchanged. There is no separate permission system. A rule `mcp__server` covers all tools of the server.
2. **Claims are not trusted.** `readOnlyHint` only affects whether the user is asked; the default is "changes things". `deny` and the plan-mode check cannot be bypassed.
3. **Their own JSON Schema.** A `Tool.jsonSchema` field was added; the server's schema goes to the model as is and the server validates (we did not try to convert to zod: lossy and error-prone).
4. **Project configuration is behind the trust gate** (same reasoning as [ADR-0004](0004-project-trust-gate.md)): commands are shown and no server starts until the exact file content is approved.
5. **No environment leak.** A stdio server gets a safe default environment plus the explicit `env`; `${VAR}` keeps secrets out of the configuration file.
6. **Failures are tolerated, the list is fixed.** A server that cannot start becomes a warning; the tool list is fixed at session start (cache-friendly prefix, [ADR-0005](0005-stable-prompt-prefix.md)).

## Consequences

- The token cost depends on the server; `usta mcp list` shows an estimate and `tools` narrows it. 4 small tools measured ≈146 tokens; the warning threshold for big servers is 1,500.
- Only tools are supported (no prompts, resources or OAuth).
- A trap found while testing: when the test server could not resolve `zod`, the connection silently ended as "Connection closed"; diagnosing needed running the server directly. The test server takes `zod` from `@usta/sdk`.
