# ADR-0009: MCP: araçlar aynı kapıdan, yapılandırma güven kapısında

**Durum:** Kabul edildi · **Tarih:** 2026-10-29

## Bağlam

MCP sunucuları usta'ya sınırsız harici araç ekler. İki risk vardır: (1) araçlar modelin eline güç verir ama sunucunun beyanları (ör. "salt okuma") doğrulanamaz; (2) yapılandırma depodan gelirse `command` alanı kullanıcı adına rastgele program başlatır.

## Karar

1. **Aynı kapı.** MCP araçları `Tool` arayüzüne uyarlanır (`mcp__sunucu__araç`); izin motoru, hook'lar, checkpoint, çıktı sınırlayıcı ve `auto` sınıflandırıcısı hepsi aynen işler. Ayrı bir izin sistemi yoktur. `mcp__sunucu` kuralı sunucunun tüm araçlarını kapsar.
2. **Beyan güvenilmez.** `readOnlyHint` yalnızca sorulup sorulmayacağını etkiler; varsayılan "değişiklik yapar"dır. `deny` ve plan modu denetimi aşılamaz.
3. **Kendi JSON Şeması.** `Tool.jsonSchema` alanı eklendi; sunucunun şeması modele olduğu gibi gider, doğrulamayı sunucu yapar (zod'a çevirmeye çalışmadık: kayıp ve hata kaynağı).
4. **Proje yapılandırması güven kapısında** ([ADR-0004](0004-project-trust-gate.md) ile aynı gerekçe): komutlar gösterilir, dosyanın tam içeriğine bağlı onay alınmadan sunucu başlatılmaz.
5. **Ortam sızdırılmaz.** stdio sunucuya güvenli varsayılan ortam ve açıkça yazılan `env` gider; `${VAR}` ile gizli bilgi yapılandırma dosyasının dışında kalır.
6. **Hata tolere edilir, liste sabittir.** Açılamayan sunucu uyarı olur; araç listesi oturum başında sabitlenir (önbellek dostu önek, [ADR-0005](0005-stable-prompt-prefix.md)).

## Sonuçlar

- Token maliyeti sunucuya bağlıdır; `usta mcp list` tahmini gösterir, `tools` listesi daraltır. 4 küçük araç ≈146 token ölçüldü; büyük sunucular için uyarı eşiği 1.500.
- Yalnızca araçlar desteklenir (prompt/kaynak/OAuth yok).
- Test sırasında bulunan tuzak: test sunucusu `zod`'u çözemeyince bağlantı sessizce "Connection closed" ile düştü; tanı için sunucuyu doğrudan çalıştırmak gerekti. Test sunucusu `zod`'u `@usta/sdk` üzerinden alır.
